menu_book Manual de Usuario

Bienvenido a HomeCalc, tu aplicación personal para gestionar ingresos, gastos y análisis financiero. Este manual explica todas las funcionalidades disponibles.

📊 Panel Principal

Accede a Home para ver un resumen de tus movimientos financieros actuales. Aquí encontrarás:

  • Resumen de ingresos y gastos del período
  • Gráficos de distribución por categoría
  • Acceso rápido a las principales funciones

💰 Gestión de Movimientos

Registrar movimientos:

  • Usa Registro para registrar nuevos movimientos (ingresos o gastos)
  • Ingresa el concepto, importe, fecha y periodicidad si aplica

Gestionar movimientos:

  • Gestionar Movimientos - Filtra, edita y elimina movimientos registrados
  • Análisis de Movimientos - Visualiza análisis detallados de tus transacciones

📈 Gestión de Ingresos

Accede a Ingresos para gestionar:

  • Ingresos Periódicos - Ingresos recurrentes (sueldos, pensiones, etc.)
  • Ingresos Extra - Ingresos puntuales o esporádicos
  • Gestionar Ingresos - Edita, actualiza y elimina tus ingresos registrados
  • Registrar Ingreso - Formulario para añadir nuevos ingresos

💸 Gestión de Gastos

Accede a Gastos para gestionar:

  • Gastos Periódicos - Gastos recurrentes (alquiler, servicios, etc.)
  • Gastos Extra - Gastos puntuales o inesperados
  • Resumen de Gastos - Visualiza un resumen completo de gastos
  • Gestionar Gastos - Edita, actualiza y elimina gastos registrados
  • Registrar Gasto - Formulario para añadir nuevos gastos

🔍 Filtros y Búsqueda

En la mayoría de páginas puedes filtrar datos por:

  • Año: Selecciona el año de los movimientos a visualizar
  • Mes: Filtra por mes específico
  • Concepto: Busca por categoría o descripción
  • Periodicidad: Filtra entre movimientos periódicos, mensuales, etc.

👤 Configuración de Cuenta

  • Cambiar Contraseña - Actualiza tu contraseña de acceso
  • Contacto - Envía sugerencias, reporta problemas o contacta al soporte

💡 Consejos Útiles

  • ✓ Usa categorías/conceptos consistentes para mejor análisis de datos
  • ✓ Registra tus movimientos regularmente para mantener actualizado el historial
  • ✓ Utiliza los filtros para analizar períodos específicos
  • ✓ Los gastos y ingresos periódicos se reflejan automáticamente en análisis
  • ✓ Puedes importar decimales con punto (.) o coma (,) - el sistema los normaliza
  • ✓ Revisa siempre antes de eliminar movimientos, esta acción no se puede deshacer

⚠️ Información Importante

  • Solo el usuario autenticado puede ver sus datos
  • Los cambios se guardan inmediatamente en la base de datos
  • Puedes cambiar tu contraseña en cualquier momento desde tu cuenta
  • Para soporte o sugerencias, utiliza la página de Contacto
