MANUAL DE USUARIO

Bienvenido a HomeCalc. Este sencillo manual explica las funcionalidades principales y cómo consultarlas paso a paso.

Funciones principales 🔧

  • Registrar movimiento: Use el formulario en Registro para añadir ingresos o gastos (manual o por selección).
  • Gestionar movimientos: En Gestionar movimientos puede filtrar, editar y eliminar entradas.
  • Ingresos y Gastos: Pestañas dedicadas para ver y gestionar ingresos (extra y periódicos) y gastos (extra y periódicos).
  • Resumen y análisis: Gráficos y resúmenes en la pantalla principal permiten ver la distribución por mes y por categoría.
  • Periodos y filtros: Use filtros por año/mes/periodicidad para ver datos específicos.

Consejos rápidos 💡

  • Use la opción de conceptos predefinidos para mantener consistencia en reportes.
  • Para importes con decimales, use punto o coma; el sistema normaliza ambos.
  • Revise el Histórico antes de eliminar movimientos irreversibles.

Nota: Para encontrar movimientos o conceptos, use las páginas de Registro o Gestionar Movimientos.
